# Project page layouts

The live site was restored before this repository captured its complete source.
For this update, actual live HTML and CSS were captured under
`source/live-layout-baseline-20261107/`. Preserve those bytes as baseline evidence;
new page layouts must retain existing writing and artwork. Shared `assets/site.css`
was synchronized to its existing live bytes, not redesigned or deployed.

- Meaning: nine square image frames in the owner’s row-major order. Taxonomy and
  & Prays share the centre square. Original descriptions/downloads remain with
  their cards; the closing Islam text remains below the grid.
- Foundations: 3×3 spatial board, empty lower-left. Top: original text / counsel /
  warning. Middle: roots / central principles / practice. Bottom: empty / mercy /
  The Abyss. All panels come from the two supplied PDFs, not the annotated image.
  `source/project-layout-assets.json` records checksums, pages and rotations.
- Intentions: all 19 original images, using the same focus/thumbnail component as
  Diagrams. Thumbnails are separate, smaller assets.
- The Heart: four original studies, five Lost Unicorn pages in a bounded carousel,
  then the mountain. No autoplay. The story’s previous/next stop at the ends.
- Decisions: full uncropped spiral above a spatial board. Upper geometry / left
  call and skull / central receipt / right coil / lower heart. The upper detail
  is a crop linked to its full original. Other full-size artwork is unchanged.
- Dialogue: all seven essays, search/year filters, reading estimates, RSS, and
  persistent catalogue and newer/older navigation in each essay. Original prose
  and the four archived comments are preserved. A response link opens email;
  no new comment backend or public submission storage is implied.

Gallery scripts use external assets for compatibility with host security policies.
Modified-click and no-JavaScript image links retain native full-image navigation.
Spatial boards scroll within a labelled region on narrow screens, preserving their
meaningful arrangement without making the whole page overflow.

Browser checks cover 1280px and 390px layouts, all 19 Intentions selections, story
end stops, catalogue filter restoration, and no page-wide horizontal overflow.
